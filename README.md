# DevOps Practice

Лабораторные работы по дисциплине `DevOps: практики и инструменты`.

## Авторы

- Воробьев Алексей
- Гринев Кирилл

## О репозитории

Репозиторий содержит выполненные лабораторные работы, каждая из которых расположена в собственной директории и посвящена отдельному аспекту практик и инструментов `DevOps`.

## Лабораторные работы

- `lab_1` — развертывание `Apache Airflow` в `Docker Compose` и реализация пользовательского `DAG` с вычислениями.
- `lab_2` — интеграция `Airflow` со `Spark` и запуск `spark-job` через `SparkSubmitOperator`.
- `lab_3` — развитие лабораторной со стеком `Airflow + Spark` и адаптация CI/CD-части задания под `GitHub Actions`.
- `lab_4` — добавление observability-стека `Loki`, `Alloy`, `Prometheus`, `Grafana` и автоматизация базовой настройки мониторинга и визуализации.
